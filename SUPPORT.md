# Support

Thanks for using or building on EMP-Guardian. Here's where to go depending on
what you need.

## I have a question about EMP physics, shielding design, or how to use the project

Open a [GitHub Discussion](https://github.com/Ciprian-LocalPulse/EMP-Guardian/discussions)
if enabled, or a regular [issue](https://github.com/Ciprian-LocalPulse/EMP-Guardian/issues)
otherwise. Please check [`docs/`](docs/) first — many common questions
(theory of operation, hardware specs, test procedures, compliance) are
already answered there, and [`MANIFESTO.md`](MANIFESTO.md) documents the
project's known epistemic limitations.

## I found a bug or the firmware/software isn't behaving as documented

Open a [bug report issue](https://github.com/Ciprian-LocalPulse/EMP-Guardian/issues/new/choose)
using the bug report template. Include your board, build command, and
(for firmware issues) whether `make test` passes on your machine.

## I want to propose a feature or a design change

Open a [feature request issue](https://github.com/Ciprian-LocalPulse/EMP-Guardian/issues/new/choose),
or read [`CONTRIBUTING.md`](CONTRIBUTING.md) and open a pull request
directly if you already have a working change.

## I found a security vulnerability

Do **not** open a public issue. Follow the private reporting process in
[`SECURITY.md`](SECURITY.md) instead.

## I want to contact the maintainer directly

See the contact details in [`README.md`](README.md#author-and-acknowledgements)
or [`CITATION.cff`](CITATION.cff).
